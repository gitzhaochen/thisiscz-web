### Full Stack Personal Blog Development 18: Frontend Post Comments Design

> The frontend post comment functionality allows users to comment and reply on posts in blog article detail pages, supporting multi-level nested reply structures, infinite scroll loading, real-time comment count updates, and permission control (only comment author or admin can delete).

#### 1. Overview

**Core Features**:

- User create comments (supports commenting on posts and replying to comments)
- Query comment list (supports infinite scroll loading)
- Display comment reply count
- Delete comments (only comment author or admin can delete)
- Real-time comment count updates
- Support URL parameter auto-scroll to comment area
- Permission control (prompt login for unauthenticated users)

**Technology Stack**:

- Next.js (server-side and client-side components)
- `@tanstack/react-query`: Data fetching and state management (infinite scroll)
- `zustand`: Global user state management
- `orval`: Auto-generate type-safe API hooks
- `lucide-react`: Icon components
- `sonner`: Toast notifications
- `date-fns`: Date formatting

#### 2. Data Models and Type Definitions

**2.1 CommentDTO Type**

Comment data returned by backend includes comment-related information (auto-generated by Orval based on OpenAPI specification):

```typescript
// src/lib/api/generated/models/commentDTO.ts
export interface CommentDTO {
  id?: number
  userId?: string
  user?: UserDTO
  postId?: number
  content?: string
  createdAt?: string
  parentId?: number | null
  parent?: CommentDTOParent
  replyCount?: number // Reply count
}
```

**Field Description**:

- `id`: Comment ID
- `userId`: Comment user ID
- `user`: Comment user information (includes username, email, etc.)
- `postId`: Associated post ID
- `content`: Comment content
- `createdAt`: Creation time
- `parentId`: Parent comment ID (`null` means top-level comment)
- `parent`: Parent comment information (optional)
- `replyCount`: Reply count (how many replies this comment has)

**2.2 CommentCreationDTO Type**

Create comment request data type:

```typescript
// src/lib/api/generated/models/commentCreationDTO.ts
export interface CommentCreationDTO {
  postId: number

```

**Field Description**:

- `postId`: Required, post ID to comment on
- `parentId`: Optional, parent comment ID (`null` means top-level comment, has value means reply)

#### 4. Comment List Component Implementation (CommentList)

**4.1 Component Structure**

Implement comment list component in `src/app/[locale]/posts/[id]/components/CommentList.tsx`:

```typescript
'use client'
import { Button } from '@/components/ui/button'
import { Textarea } from '@/components/ui/textarea'
import React, { useEffect, useState } from 'react'
import CommentItem from './CommentItem'
import { Loader } from 'lucide-react'
import { toast } from 'sonner'
import { useSearchParams } from 'next/navigation'
import { useUserStore } from '@/store/userStore'
import { useGetApiCommentsInfinite, usePostApiCommentsCreate } from '@/lib/api/generated'

type Props = {
  post: any
}

const COMMENTS_PER_PAGE = 10

const CommentList = ({ post }: Props) => {
  const user = useUserStore((state: any) => state.user)
  const [newComment, setNewComment] = useState('')
  const [commentCount, setCommentCount] = useState(post.commentCount)

  // Infinite scroll query comment list
  const {
    data: comments,
    isFetching,
    refetch: refetchComments,
    fetchNextPage,
    hasNextPage,
  } = useGetApiCommentsInfinite(
    {
      postId: Number(post.id),
      pageSize: COMMENTS_PER_PAGE,
    },
    {
      query: {
        initialPageParam: 1,
        getNextPageParam: (lastPage, allPages, lastPageParam) => {
          if ((lastPage?.items?.length ?? 0) < COMMENTS_PER_PAGE) {
            return undefined // No more data
          }
          return (lastPageParam || 0) + 1 // Return next page number
        },
      },
    },
  )

  // Create comment
  const { mutate: addComment, isPending: addingComment } = usePostApiCommentsCreate({
    mutation: {
      onSuccess: () => {
        setNewComment('')
        refetchComments() // Refresh comment list
        setCommentCount((prev: number) => prev + 1) // Update comment count
      },
    },
  })

  const handleCommentDeleted = () => {
    setCommentCount((prev: number) => prev - 1)
    refetchComments()
  }

  const handleSubmitComment = async (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault()
    if (!user?.id) {
      toast.info('Please login to comment')
      return
    }
    if (!newComment.trim()) return

    await addComment({
      data: {
        content: newComment.trim(),
        postId: Number(post.id),
        parentId: null, // Create top-level comment
      },
    })
  }

  // URL parameter auto-scroll to comment area
  const searchParams = useSearchParams()
  useEffect(() => {
    const scrollTo = searchParams.get('scrollTo')
    if (scrollTo === 'comments') {
      const commentsElement = document.getElementById('comments')
      if (commentsElement) commentsElement.scrollIntoView({ behavior: 'smooth' })
    }
  }, [searchParams])

  return (
    <div className="mt-8 space-y-4">
      <h4 className="font-semibold" id="comments">
        Comments
      </h4>
      {/* Comment form */}
      <form onSubmit={handleSubmitComment} className="max-w-[800px] space-y-2">
        <Textarea
          placeholder="Enter your comment..."
          value={newComment}
          onChange={(e) => setNewComment(e.target.value)}
          rows={3}
        />
        <Button type="submit" disabled={addingComment || !newComment.trim()} size="sm" className="cursor-pointer">
          {addingComment ? 'Submitting...' : 'Submit'}
        </Button>
      </form>
      {/* Comment list */}
      {isFetching && (
        <div className="flex justify-center">
          <Loader className="h-4 w-4 animate-spin" />
        </div>
      )}
      <div className="space-y-4">
        {comments?.pages
          .flatMap((page) => page.items)
          .map((comment: any) => (
            <CommentItem
              key={comment.id}
              comment={comment}
              currentUser={user}
              onCommentDeleted={handleCommentDeleted}
              postId={post.id}
              level={0}
            />
          ))}
      </div>
      {hasNextPage && (
        <div className="flex justify-center pt-4">
          <Button
            variant="outline"
            size="sm"
            onClick={() => fetchNextPage()}
            disabled={isFetching}
            className="cursor-pointer text-gray-500 hover:bg-gray-100"
          >
            load more comments
          </Button>
        </div>
      )}
    </div>
  )
}

export default CommentList
```

**Component Function Description**:

1. **Infinite Scroll Query**:
   - Use `useGetApiCommentsInfinite` to implement infinite scroll loading
   - `getNextPageParam` function calculates next page number
   - Use `flatMap` to merge multi-page data into single array
   - `hasNextPage` determines if there's more data

2. **Create Comment**:
   - Use `usePostApiCommentsCreate` to create comment
   - Verify if user is logged in (prompt if not logged in)
   - After successful creation, clear form, refresh list, update comment count

3. **Comment Count Management**:
   - Use `useState` to manage local comment count
   - Increase count when creating comment
   - Decrease count when deleting comment

4. **URL Parameter Auto-Scroll**:
   - Listen to `scrollTo` URL parameter
   - When parameter is `comments`, automatically scroll to comment area
   - Support jumping from other pages and auto-locating to comment area

5. **UI Feedback**:
   - Show `Loader` component when loading
   - Submit button shows loading state (`Submitting...`)
   - Disable submit button when content is empty

#### 5. Comment Item Component Implementation (CommentItem)

**5.1 Recursive Component Design**

Implement comment item component (supports recursive nesting) in `src/app/[locale]/posts/[id]/components/CommentItem.tsx`:

```typescript
import { Button } from '@/components/ui/button'
import { Textarea } from '@/components/ui/textarea'
import { useGetApiCommentsInfinite, usePostApiCommentsCreate, useDeleteApiCommentsId } from '@/lib/api/generated'
import { formatDistanceToNow } from 'date-fns'
import { ChevronDown, ChevronUp, Loader, Reply, Trash2, User } from 'lucide-react'
import React, { useState } from 'react'
import { toast } from 'sonner'

type Props = {
  comment: any
  currentUser?: any
  onCommentDeleted?: () => void
  level: number // Nesting level
  postId: string
}

const REPLIES_PER_PAGE = 10

const CommentItem = ({ comment, currentUser, onCommentDeleted, level, postId }: Props) => {
  const isMaxLevel = level >= 2 // Limit maximum nesting level to 2

  const [showReplies, setShowReplies] = useState(false)
  const [repliesCount, setRepliesCount] = useState(comment.replyCount)

  // Query reply list (only query when expanded)
  const {
    data: repliesData,
    refetch: refetchReplies,
    isLoading: repliesLoading,
    fetchNextPage,
    hasNextPage,
  } = useGetApiCommentsInfinite(
    {
      postId: Number(postId),
      parentId: Number(comment.id!),
      pageSize: REPLIES_PER_PAGE,
    },
    {
      query: {
        initialPageParam: 1,
        getNextPageParam: (lastPage, allPages, lastPageParam) => {
          if ((lastPage?.items?.length ?? 0) < REPLIES_PER_PAGE) {
            return undefined
          }
          return (lastPageParam || 0) + 1
        },
        enabled: showReplies, // Only query when expanded
      },
    },
  )

  const [showReplyForm, setShowReplyForm] = useState(false)
  const [newReply, setNewReply] = useState('')

  // Delete comment
  const { mutate: deleteComment, isPending: deletingComment } = useDeleteApiCommentsId({
    mutation: {
      onSuccess: () => {
        onCommentDeleted?.()
      },
    },
  })

  const handleCommentDeleted = () => {
    setRepliesCount((prev: number) => prev - 1)
    refetchReplies()
  }

  // Create reply
  const { mutate: addReply, isPending: addingReply } = usePostApiCommentsCreate({
    mutation: {
      onSuccess: () => {
        setShowReplyForm(false)
        setNewReply('')
        refetchReplies()
        setRepliesCount((prev: number) => prev + 1)
      },
    },
  })

  const handleSubmitReply = async (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault()
    await addReply({
      data: {
        content: newReply,
        postId: Number(postId),
        parentId: Number(comment.id), // Specify parent comment ID
      },
    })
  }

  return (
    <div
      key={comment.id}
      className={`${level > 0 ? 'border-l-1 border-gray-200 pl-4' : ''} border-b-1 border-gray-200 pb-3`}
    >
      {/* Comment header: user info, time, delete button */}
      <div className="flex h-8 items-center gap-8">
        <div className="flex items-center text-xs text-gray-500">
          <User className="mr-1 size-3" />
          <span>{comment.user?.userName || 'Anonymous'}</span>
          <span className="mx-2">•</span>
          <span>
            {formatDistanceToNow(new Date(comment.createdAt), {
              addSuffix: true,
            })}
          </span>
        </div>
        {/* Permission control: only comment author or admin can delete */}
        {(comment.userId === currentUser?.id || currentUser?.role === 'admin') && (
          <Button
            variant="ghost"
            size="sm"
            onClick={() => deleteComment({ id: Number(comment.id) })}
            disabled={deletingComment}
            className="cursor-pointer text-gray-500 hover:bg-gray-100"
          >
            <Trash2 className="size-3" />
          </Button>
        )}
      </div>

      {/* Comment content */}
      <p className="mt-1">{comment.content}</p>

      {/* Comment actions: reply button, show replies button */}
      <div className="mt-1 flex items-center gap-2">
        {!isMaxLevel && (
          <Button
            variant="ghost"
            size="sm"
            className="cursor-pointer text-gray-500"
            onClick={() => {
              if (!currentUser?.id) {
                toast.info('Please login to reply')
                return
              }
              setShowReplyForm(!showReplyForm)
            }}
          >
            <Reply className="size-3" />
          </Button>
        )}
        {repliesCount > 0 && (
          <div className="flex items-center gap-1">
            <Button
              variant="link"
              size="sm"
              className="cursor-pointer text-xs text-gray-500"
              onClick={() => setShowReplies(!showReplies)}
            >
              {repliesCount} replies
              {showReplies ? <ChevronDown className="size-3" /> : <ChevronUp className="size-3" />}
            </Button>
          </div>
        )}
      </div>

      {/* Reply form */}
      <div className="ml-2">
        {showReplyForm && (
          <div className="">
            <form className="max-w-[800px]" onSubmit={handleSubmitReply}>
              <Textarea
                placeholder="Enter your reply..."
                name="reply"
                value={newReply}
                onChange={(e) => setNewReply(e.target.value)}
              />
              <div className="flex gap-2">
                <Button
                  variant="outline"
                  size="sm"
                  className="mt-2 cursor-pointer text-gray-500"
                  type="submit"
                  disabled={addingReply}
                >
                  {addingReply ? 'replying...' : 'reply'}
                </Button>
                <Button
                  variant="link"
                  size="sm"
                  className="mt-2 cursor-pointer text-gray-500"
                  onClick={() => setShowReplyForm(false)}
                >
                  cancel
                </Button>
              </div>
            </form>
          </div>
        )}

        {/* Reply list */}
        {showReplies && (
          <div className="mt-2">
            {repliesLoading && (
              <div className="flex justify-center">
                <Loader className="h-4 w-4 animate-spin" />
              </div>
            )}
            {repliesData?.pages.flatMap((page) => page.items).length && (
              <div className="replies">
                {repliesData?.pages
                  .flatMap((page) => page.items)
                  .map((reply: any) => (
                    <CommentItem
                      key={reply.id}
                      comment={reply}
                      currentUser={currentUser}
                      onCommentDeleted={handleCommentDeleted}
                      level={level + 1} // Recursive call, level +1
                      postId={postId}
                    />
                  ))}
              </div>
            )}

            {hasNextPage && (
              <Button
                variant="outline"
                size="sm"
                className="mt-2 text-gray-500"
                onClick={() => fetchNextPage()}
                disabled={repliesLoading}
              >
                load more replies
              </Button>
            )}
          </div>
        )}
      </div>
    </div>
  )
}

export default CommentItem
```

**Component Function Description**:

1. **Recursive Component Design**:
   - Use `level` parameter to control nesting level
   - Limit maximum nesting level to 2 (`isMaxLevel = level >= 2`)
   - Use `CommentItem` recursively in reply list, `level + 1`

2. **On-Demand Reply Loading**:
   - Use `enabled: showReplies` to control query timing
   - Only query reply list when user clicks "show replies"
   - Avoid unnecessary API requests, improve performance

3. **Permission Control**:
   - Delete button: Only visible to comment author (`comment.userId === currentUser?.id`) or admin (`currentUser?.role === 'admin'`)
   - Reply button: Prompt login when unauthenticated users click

4. **Reply Management**:
   - Use `showReplyForm` to control reply form show/hide
   - Specify `parentId` as current comment ID when creating reply
   - Refresh reply list and update reply count after successful reply

5. **UI Design**:
   - Use `border-l` and `pl-4` to add left border and indent for nested replies
   - Use `formatDistanceToNow` from `date-fns` to display relative time (e.g., "2 hours ago")
   - Use `lucide-react` icons to enhance visual effects

#### 9. User Experience Optimization

**9.1 Infinite Scroll Loading**

Use React Query's `useInfiniteQuery` to implement infinite scroll:

```typescript
const {
  data: comments,
  fetchNextPage,
  hasNextPage,
} = useGetApiCommentsInfinite(
  { postId: Number(post.id), pageSize: COMMENTS_PER_PAGE },
  {
    query: {
      getNextPageParam: (lastPage, allPages, lastPageParam) => {
        if ((lastPage?.items?.length ?? 0) < COMMENTS_PER_PAGE) {
          return undefined // No more data
        }
        return (lastPageParam || 0) + 1 // Return next page number
      },
    },
  },
)
```

**Advantages**:

- Load on demand, reduce initial load time
- Support "load more" button, users can control load timing
- Automatically manage pagination state, no need to handle page numbers manually

#### 12. Common Issues

**Q: Infinite scroll not working?**

A: Check the following:

- Is `getNextPageParam` function correctly returning next page number
- Is `hasNextPage` correctly determining if there's more data
- Is backend API correctly returning paginated data

**Q: Reply list not displaying?**

A: Confirm:

- Is `enabled: showReplies` correctly set
- Is `parentId` parameter correctly passed
- Is backend API correctly returning reply list

**Q: List not updating after deleting comment?**

A: Ensure:

- `onCommentDeleted` callback function correctly calls `refetchComments()`
- Comment count state is correctly updated

**Q: URL parameter auto-scroll not working?**

A: Check:

- Is `useSearchParams` correctly used
- Is `id="comments"` correctly set
- Is `scrollIntoView` method correctly called

**Q: Nested reply level limit?**

A: Current implementation limits maximum nesting level to 2 (`level >= 2`), can modify `isMaxLevel` condition in `CommentItem` component to adjust level limit.
