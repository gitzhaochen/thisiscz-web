### Full Stack Personal Blog Development 16: Frontend Post Like Design

> The frontend post like functionality allows users to like and unlike posts in blog article lists and detail pages, displaying like counts in real-time and the current user's like status.

#### 1. Overview

**Core Features**:

- User like/unlike posts
- Display post like count in real-time
- Display if current user has liked (red highlight)
- Prompt login when unauthenticated users click
- Disable button during like operation to prevent duplicate clicks
- Optimistic Update to improve user experience

**Technology Stack**:

- Next.js (server-side and client-side components)
- `@tanstack/react-query`: Data fetching and state management
- `zustand`: Global user state management
- `orval`: Auto-generate type-safe API hooks
- `lucide-react`: Icon components
- `sonner`: Toast notifications

#### 2. Data Models and Type Definitions

**2.1 PostDTO Type**

Post data returned by backend includes like-related information (auto-generated by Orval based on OpenAPI specification):

```typescript

export interface PostDTO {
  id?: number
```

**Field Description**:

- `likeCount`: Total like count for the post (backend optimizes through batch queries to avoid N+1 problem)
- `isLikedByCurrentUser`: Whether current logged-in user has liked (false when not logged in)

#### 4. Like Component Implementation

**4.1 LikeAction Component**

Implement like component in `src/app/[locale]/posts/components/LikeAction.tsx`:

```typescript
'use client'
import { Button } from '@/components/ui/button'
import { usePostApiPostsPostLike } from '@/lib/api/generated'
import { Heart } from 'lucide-react'
import { useLocale } from 'next-intl'
import { useState } from 'react'
import { toast } from 'sonner'
import { useUserStore } from '@/store/userStore'

type Props = {
  post: any
}

const LikeAction = ({ post }: Props) => {
  const user = useUserStore((state: any) => state.user)
  const locale = useLocale()
  const [isLiked, setIsLiked] = useState<boolean>(post.isLikedByCurrentUser)
  const [likeCount, setLikeCount] = useState<number>(post.likeCount)

  const { mutate: likePost, isPending: likingPost } = usePostApiPostsPostLike({
    mutation: {
      onSuccess: () => {
        setIsLiked(true)
        setLikeCount((prev) => prev + 1)
      },
    },
  })

  const { mutate: unlikePost, isPending: unlikingPost } = usePostApiPostsPostLike({
    mutation: {
      onSuccess: () => {
        setIsLiked(false)
        setLikeCount((prev) => prev - 1)
      },
    },
  })

  const handleLikeToggle = () => {
    if (!user?.id) {
      toast.info('Please login to like this post')
      return
    }
    if (isLiked) {
      unlikePost({ data: { postId: Number(post.id), isLiked: false } })
    } else {
      likePost({ data: { postId: Number(post.id), isLiked: true } })
    }
  }

  return (
    <Button
      variant="ghost"
      size="sm"
      onClick={handleLikeToggle}
      disabled={likingPost || unlikingPost}
      className={`flex cursor-pointer items-center gap-1 ${isLiked ? 'text-red-500' : 'text-gray-500'}`}
    >
      <Heart className={`h-4 w-4 ${isLiked ? 'fill-current' : ''}`} />
      <span>{likeCount}</span>
    </Button>
  )
}

export default LikeAction
```

**Component Function Description**:

1. **State Management**:
   - `isLiked`: Whether current user has liked (initialized from `post.isLikedByCurrentUser`)
   - `likeCount`: Like count (initialized from `post.likeCount`)

2. **User Authentication Check**:
   - Use `useUserStore` to get current user information
   - Show prompt when unauthenticated users click (using `toast.info`)

3. **Like/Unlike Operations**:
   - Use two separate `usePostApiPostsPostLike` hooks
   - Handle like and unlike success callbacks separately
   - Update local state in `onSuccess` (optimistic update)

4. **UI Feedback**:
   - Show red (`text-red-500`) and filled heart icon (`fill-current`) when liked
   - Show gray (`text-gray-500`) and hollow icon when not liked
   - Disable button during request (`disabled={likingPost || unlikingPost}`)

5. **Icons and Styles**:
   - Use `Heart` icon from `lucide-react`
   - Icon is filled when liked, hollow when not liked
   - Use Tailwind CSS class names to control styles

#### 7. User Experience Optimization

**7.1 Optimistic Update**

Like component uses optimistic update strategy, updating UI before API request succeeds:

```typescript
const { mutate: likePost, isPending: likingPost } = usePostApiPostsPostLike({
  mutation: {
    onSuccess: () => {
      setIsLiked(true)
      setLikeCount((prev) => prev + 1) // Update UI immediately
    },
  },
})
```

**Advantages**:

- Users see feedback immediately after clicking, no need to wait for network request
- Improve user experience, reduce perceived latency
- If request fails, can rollback state in `onError`

**7.2 Prevent Duplicate Clicks**

Disable button during request:
